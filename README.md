# Haven · 氛围感拍照打卡

一款拍照打卡地种草 Web 原型：帮你发现「在这里能拍出什么氛围感照片」的地方，也能像发小红书一样上传你自己挖到的宝藏点位。

## 怎么运行

在项目目录运行 `node server.js`，然后浏览器打开 `http://localhost:3000`（数据存在浏览器 localStorage）。
地图使用 MapLibre GL JS + MapTiler 底图，路线规划走 OSRM 公共路由服务，需要联网加载；断网时会自动降级为“附近打卡点”列表。

## 已实现功能

- **首页**：搜索框 + 风格/场景分类胶囊 + 横滑“本周精选” + 小红书式双列推荐流
- **底部磨砂悬浮 Tab 栏**：首页 / 记录 / 上传 / 地图 / 我的（居中金色上传按钮）
- **搜索**：按地点名、城市、风格标签搜索；支持城市、免费、室内/室外筛选
- **地图（附近打卡点）**：底部“地图”Tab 打开即定位当前位置；缩小时打卡点是金色圆点，放大（zoom ≥ 14）自动变成「缩略图 + 地点名称」卡片，点击直达详情（图片按需加载，离线自动回落渐变占位图）；下方列表按距离排序显示附近点位
- **详情页**：图片轮播、地址/营业时间/门票、出片风格标签、出片亮点、拍照小 Tips、实拍图集、相关推荐、收藏 + 分享 + 前往
- **前往（路线规划）**：详情页点“前往”会跳转地图并自动定位，按当前位置绘制驾车 / 步行真实路线，显示预计用时与距离；公共交通模式一键跳到 Google / Apple 地图规划并导航
- **上传打卡点**：
  - 进入页面自动定位当前城市（浏览器定位 → 逆地理编码，离线时按坐标就近估算），并记录经纬度用于地图展示
  - 只输入「尖沙咀的海边餐厅」这类地点名，自动识别区域（尖沙咀→香港）、城市和场景类型
  - 输入餐厅 / 街道 / 地标名称时，会用 MapTiler 地点搜索列出真实匹配结果（名称 + 所在位置），点选后回填真实地址与经纬度，避免落到错误位置
  - 2-9 张照片上传，自动压缩后存在本地
  - 提交后进入“待审核”，可在 我的 → 审核台（演示）模拟通过/拒绝
- **收藏 / 记录 / 我的**：收藏在 我的 → 我的收藏（方便下次去拍）、浏览历史、昵称编辑、数据统计
- **我的投稿（可编辑）**：投稿列表显示每条状态（审核中 / 已上线 / 已拒绝 / 已下架）与管理员原因；点“编辑”可重新上传照片、修改地点、场景、风格、文案与消费提示，保存后回到“审核中”重新审核，也可删除自己的投稿
- **多语言**：我的 → 语言，可选「跟随系统 / 简体中文 / 繁體中文 / English」；繁体由 OpenCC 实时转换，英文走内置词典（`i18n.js`），系统语言不是中英时自动用英文
- **离线兜底**：示例配图在线加载 Unsplash，断网时自动切换为品牌渐变占位图；地图不可用时展示列表，页面不破版

## 设计

- 主色 #D4B886 暖金、背景 #F7F8FA、卡片白色、阴影 rgba(0,0,0,.06)
- 底部悬浮玻璃 Tab 栏（毛玻璃 + 金色径向光晕），跟随 iOS 安全区
- 移动端优先，最大宽度 480px 居中

## 文件

- `index.html` — 页面骨架 + 底部 Tab 栏 + PWA 配置（含 MapLibre GL、OpenCC 依赖）
- `styles.css` — 全部样式
- `app.js` — 数据、路由、首页/搜索/详情/地图/上传与编辑/收藏/记录/我的/审核台/路线规划
- `i18n.js` — 多语言词典与运行时翻译（简 / 繁 / 英）
- `docs/PLAN.md` — 后端、分享、iOS 打包与上架的完整方案存档
- `server.js` — 本地预览服务器（`--lan` 可让同一 Wi-Fi 的朋友访问）
- 示例数据已清空，`starterSpots` / `moreSpots` 为空数组，只展示真实投稿

## 分享给朋友 / 试用

### 方式一：同一 Wi-Fi（最快，1 分钟）

```bash
node server.js --lan
```

终端会打印 `http://<你的局域网IP>:3000`（例如 `http://192.168.3.167:3000`），朋友连同一个 Wi-Fi 用手机浏览器打开即可。
第一次运行 Windows 可能弹防火墙提示，选择“允许访问（专用网络）”。

注意：局域网是 http，浏览器会**禁用定位**（只在 https 或 localhost 下可用），朋友需要手动点城市；地图、搜索、上传、浏览都正常。

### 方式二：免费 HTTPS 托管（推荐，定位可用）

项目是纯静态站点，把 `index.html`、`styles.css`、`app.js` 传到任意静态托管即可（仓库里已准备 `haven-分享版.zip`）：

- Netlify Drop：打开 https://app.netlify.com/drop，把 zip 拖进去 → 得到 `https://xxx.netlify.app` 链接
- tiiny.host / Cloudflare Pages：同样支持拖拽或上传
- Vercel：没有拖拽入口，用 CLI 或 GitHub——
  - CLI：`npm i -g vercel` → 在本目录运行 `vercel`（Framework 选 Other、构建命令留空）→ 再 `vercel --prod` 得到 https 链接
  - GitHub：把 `index.html` / `styles.css` / `app.js` 推到仓库 → Vercel「Add New → Project」导入 → Deploy
  - 注意：Hobby 计划仅限非商业用途；若朋友打开看到 Vercel 登录页，去 Project Settings → Deployment Protection 关闭 “Vercel Authentication”

拿到 https 链接后发给朋友，定位、真实地点搜索都能正常用。

### 方式三：临时公网隧道（不改代码、不部署）

装上 cloudflared 后运行：

```bash
cloudflared tunnel --url http://localhost:3000
```

会得到一个临时 `https://xxx.trycloudflare.com` 链接，可以随时关闭。

### 关于数据与安全

- 演示版数据存在**每个访问者自己的浏览器**（localStorage），朋友看到的是示例点位 + 他自己上传的内容；要多人共享同一份数据需要接后端数据库。
- MapTiler key 写在前端可被看到；正式公开前建议在 MapTiler 后台把 key 限制为你的域名（Allowed origins）。
